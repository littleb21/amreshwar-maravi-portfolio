# Amreshwar Maravi — Personal Portfolio

An ultra-sleek, interactive, dark glassmorphic personal portfolio website featuring smooth transitions, dynamic ambient lighting, responsive tab switching, and project showcase modals.

---

## 🌟 Features

- **Cinematic Dark Glassmorphic Design**: Polished aesthetics with multi-layered shadows, subtle glow accents, and frosted glass panels (`backdrop-filter`).
- **Interactive Floating Dock**: Quick tab navigation between:
  - **Home**: Hero presentation, "Open to work" glowing radar indicator, stats counters, contact pills with click-to-copy functionality.
  - **Summary**: Professional background, story, and core design & development philosophy.
  - **Experience & Projects**: Curated case studies (including *Flowstate* and *Aetheria AI*) with interactive deep-dive modals.
  - **Skills & Arsenal**: Tech stack badges (Figma, Framer, React, JavaScript, CSS3, Photoshop, etc.), language proficiency bars, and credentials.
  - **Links & Contact**: Direct social links and quick message inquiry form.
- **Micro-Interactions**: Ambient mouse lighting, 3D card tilt physics, copy-to-clipboard toast notifications, and CV preview & print handler.
- **Zero Heavy Framework Dependencies**: Pure HTML5, Vanilla CSS3, and ES6+ JavaScript for blazing performance and instant load times.

---

## 🚀 Quick Start

### 1. View Directly
Simply open `index.html` in any modern web browser.

### 2. Run Local Server (PowerShell)
To serve locally with live assets:
```powershell
powershell -ExecutionPolicy Bypass -File .\server.ps1
```
Then visit [http://localhost:5500](http://localhost:5500).
